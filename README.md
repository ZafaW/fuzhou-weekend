## ✨ 能做什么

- **按月龄挑**：填宝宝出生日期，自动换算月龄，按适龄程度给每个地点打分排序
- **按天气挑**：下雨 / 闷热优先室内和空调房，晴天优先户外和树荫
- **按距离挑**：以你设定的起点为中心，按车程远近筛；起点可以随时改
- **手机端一屏 8 条**：一行一个地点，只看名字、距离、车程和一两个特色标签，点一下原地展开吃饭、看点、雷点、适龄建议
- **每天都不一样**：每天推荐清单会自动更新，去过的地方也不会重复推荐
- **离线可用**：装到手机桌面后，断网也能打开看当天的清单

## 📄 关于数据

页面里的地点信息（名称、地址、评分、开放时间）来自高德地图公开数据，仅供个人出行参考。出发前请再确认一下开放时间和门票，季节、天气、临时闭园都可能变化。

各景点的「适合这个月龄」「雷点」等描述是按规则自动生成的参考意见，不是权威结论。
