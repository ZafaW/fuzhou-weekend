# 福州带娃周末出行

福州亲子周末出行指南。按宝宝月龄、当天天气、距起点远近，从福州市区及周边的公园、动物园、海洋馆、沙滩、图书馆、科技馆里，筛出今天最值得去的几个地方。

一个纯静态网页，打开即用，可装到手机主屏当 App。

## ✨ 能做什么

- **按月龄挑**：填宝宝出生日期，自动换算月龄，按适龄程度给每个地点打分排序
- **按天气挑**：下雨 / 闷热优先室内和空调房，晴天优先户外和树荫
- **按距离挑**：以你设定的起点为中心，按车程远近筛；起点可以随时改
- **手机端一屏 8 条**：一行一个地点，只看名字、距离、车程和一两个特色标签，点一下原地展开吃饭、看点、雷点、适龄建议
- **每日自动更新**：每天 08:00 定时任务从高德拉一遍周边地点，自动去重、分类、评分，生成当天的推荐清单
- **离线可用**：当日清单内嵌在页面里，装到主屏后断网也能打开

## 🛠 怎么做的

纯静态页面，没有构建步骤，没有前端框架，没有数据库。

```
福州带娃周末出行.html     页面模板（干净版，数据位留空）
index.html                发布版（模板 + 当日数据快照）
build_snapshot.js         快照生成器：拉高德 → 过滤 → 注入模板
run_daily.js              每日定时任务：生成 + 自动补全 + 回写仓库
sw.js / manifest.webmanifest   让页面可装到主屏、可离线
```

- 地图用 [Leaflet](https://leafletjs.com/)，底图与地理编码走高德
- 地点数据来自高德 POI 检索，按关键词多路检索后去重、按类型和评分过滤
- 托管在 GitHub Pages，数据由每日定时任务写回仓库，不需要独立服务器

## 📄 关于数据

页面里的地点信息（名称、地址、评分、开放时间）来自高德地图公开 POI 接口，仅供个人出行参考。出发前请再确认一下开放时间和门票，季节、天气、临时闭园都可能变化。

各景点的「适合这个月龄」「雷点」等描述由本项目的评分规则生成，是参考意见，不是权威结论。
