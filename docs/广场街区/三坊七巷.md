# 三坊七巷

- **分类**：广场街区
- **来源**：知识库 SPOT_NOTES（已精修）
- **更新**：2026/10/24

## 🎯 玩法推荐

市区千年坊巷地铁1/4号线东街口站步行5分钟，带娃边逛古厝边学非遗；严复故居少儿图文展区、小黄楼园林宅院；南后街非遗体验馆（牛角梳/年画/油纸伞，亲子套票约120）；同利肉燕永和鱼丸没牙伯花生汤芋泥老字号；游客中心有母婴室免费热水儿童导览图；联票70成人1.2m以下免

## ⚠️ 注意事项

周末主街区人挤人建议9点前或从小巷（衣锦坊/文儒坊）进；收费展馆小又闷带娃别进；中午12-14点最热安排室内/树荫；古厝民宿多老宅改建无电梯隔音差，带婴儿不建议住核心区；拒绝高价讲解周末有志愿者免费讲解

## 🍚 餐饮建议

南后街老字号（同利肉燕/永和鱼丸/没牙伯花生汤）人均80；巷内老店更地道；避开主街网红店
