# 平潭

- **分类**：沙滩海滨
- **来源**：知识库 SPOT_NOTES（已精修）
- **更新**：2026/10/24

## 🎯 玩法推荐

福州看真海首选高铁直达平潭站；龙凤头/坛南湾/田美澳大片免费细沙沙滩娃挖沙踩浪一下午浅水安全推车方便；模镜村/坛南湾礁石滩免费赶海抓螃蟹捡贝壳（查潮汐表退潮前后2h）；环岛路风车落日；10月错峰人少；玻璃海绝美

## ⚠️ 注意事项

赶海务必查潮汐精灵小程序退潮前后2h才出货；礁石湿滑穿防滑鞋不让孩子独自近礁石；海边紫外线强防晒；昼夜温差大薄外套+换洗衣物；热门民宿节假日提前订；青峰山等野礁石区不建议带娃

## 🍚 餐饮建议

居民区老店清淡海鲜面/海蛎煎/时来运转/炒花蛤人均五六十；市场买海鲜找店加工更省；避开海边网红大排档
