# 旗山湖

- **分类**：乐园游乐
- **来源**：知识库 SPOT_NOTES（已精修）
- **更新**：2026/10/24

## 🎯 玩法推荐

闽侯上街福州第一大绿色生态景观湖（水域近3个西湖），10公里环湖步道福州最长；湖畔大草坪露营野餐骑行；粉黛乱子草（秋日盛花）逆光出片；旗旗Hi森动物城亲近羊驼水豚梅花鹿看小猪跳水；旗旗探险乐园摩天轮大摆锤；南面水幕投影（周五至周日19:00起每30分钟一场）；免费停车

## ⚠️ 注意事项

园区大步行多带婴儿车；部分区域无树荫夏季防晒；停车免费但车位有限早到；周末人多

## 🍚 餐饮建议

园内小卖部；周边大学城商圈餐饮；自驾导航「旗山湖公园」
