# 儿童公园

- **分类**：博物馆科普
- **来源**：知识库 SPOT_NOTES（已精修）
- **更新**：2026/10/24

## 🎯 玩法推荐

福州城北遛娃天花板，9.6万㎡、73%绿化，免费入园；分小伙伴园（1-4岁软包低滑梯摇摇马沙地安全系数高）、活力园（免费无动力攀爬网大滑梯秋千）、戏水园（夏6-10月浅水免费）、艺术园（郁金香花海+科普）、收费游乐（旋转木马碰碰车摩天轮10-30元）；母婴室配护理台热水；与动物园/森林公园相邻可一日连玩

## ⚠️ 注意事项

园内遮阳少正午暴晒带防晒帽小风扇；热门收费项目周末排队；休息区较少自带水壶；无大型餐厅正餐去附近商场（东门麦当劳甜品站）

## 🍚 餐饮建议

园内小吃摊/自动贩卖机/东门麦当劳甜品站；自带零食野餐垫草坪野餐；正餐去新店镇或五四北泰禾
