# 欧乐堡

- **分类**：博物馆科普
- **来源**：知识库 SPOT_NOTES（已精修）
- **更新**：2026/10/24

## 🎯 玩法推荐

永泰葛岭4A海洋乐园，150米海底隧道鲨鱼鳐鱼头顶游过超沉浸；白鲸飞吻互动、企鹅、北极熊、美人鱼水下芭蕾+海豚360°翻转表演；水母宫光影、探秘亚马逊雨林、科普馆边玩边学；室内空调凉爽不晒，适合半天到一天

## ⚠️ 注意事项

距市区远（永泰车程约1h+）单程成本高；门票偏贵（成人约159/儿童优待108/亲子1大1小199）；馆内餐饮价格偏高；有娃反映场馆通风致咳嗽（个别）；表演固定场次提前占位；1.2m以下可能免

## 🍚 餐饮建议

馆内有餐厅小卖部但偏贵；建议自带水
