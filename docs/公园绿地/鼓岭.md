# 鼓岭

- **分类**：公园绿地
- **来源**：知识库 SPOT_NOTES（已精修）
- **更新**：2026/10/24

## 🎯 玩法推荐

福州著名避暑胜地比市区低好几度盛夏清凉；柱里景区平缓步道婴儿车能推、可露营观星（提前1天「鼓岭文旅」公众号预约）；柳杉王公园、大梦书屋老上海风、鼓岭老市场自助投币、柯坪水库垂钓、南洋溪光脚玩水；百年别墅民宿+山林无边泳池；农家菜「鼓岭四宝」（亥菜炒蛋必点）

## ⚠️ 注意事项

盘山公路多弯晕车娃备晕车贴；山里早晚凉必带薄外套；露营需提前1天预约；部分老宅民宿隔音一般低龄午睡受影响；自驾山路

## 🍚 餐饮建议

鼓岭四宝（亥菜/萝卜/地瓜/佛手瓜）、鼓岭十大碗、游客中心咖啡馆；露营自带食材
