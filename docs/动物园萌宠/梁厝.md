# 梁厝

- **分类**：动物园萌宠
- **来源**：知识库 SPOT_NOTES（已精修）
- **更新**：2026/10/24

## 🎯 玩法推荐

仓山三江口千年理学古村，白墙黛瓦马鞍墙，地铁1/6号线梁厝站步行5分钟；13处文保+30多座明清古建；四季花海（油菜花/向日葵/格桑花）+茉莉花田，大片草坪可免费露营野餐；萌宠乐园羊驼兔子+螃蟹池捞鱼、骑马；非遗手作（油纸伞/拓印/漆扇）；春伦茶馆喝茉莉花茶听评话

## ⚠️ 注意事项

街区大步行多带婴儿车；夏季防晒防蚊；室内展馆9:30-22:00；部分体验收费（喜乐卡/手作）；停车5元且免费停车都有

## 🍚 餐饮建议

柴火锅边、梁心元宵、鱼丸、擂茶人均30-50；春伦大众茶馆人均15-25；古厝民宿200-350/晚
