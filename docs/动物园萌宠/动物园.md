# 动物园

- **分类**：动物园萌宠
- **来源**：知识库 SPOT_NOTES（已精修）
- **更新**：2026/10/24

## 🎯 玩法推荐

福州老牌山地动物园，依山错落像天然氧吧；小熊猫有夏日冰床、亚洲象吃窝窝头，动物被照料得有灵气；海狮可抱拍、金丝猴长臂猿百看不厌；门票亲民（成人30/优待15），观光车单程10元

## ⚠️ 注意事项

全程往返约5公里且多上下坡石板路，婴儿推车推行颠，1岁多娃累；观光车车次少、高峰排队；16:30停止入园别晚到；老虎狮子常睡觉看不到；味道偏臭建议戴口罩；熊猫世界老馆拆除期可能看不到熊猫

## 🍚 餐饮建议

园内餐饮配套弱建议自带；门口广场小卖部；就近新店镇餐饮
