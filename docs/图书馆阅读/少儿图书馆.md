# 少儿图书馆

- **分类**：图书馆阅读
- **来源**：知识库 SPOT_NOTES（已精修）
- **更新**：2026/10/24

## 🎯 玩法推荐

市区遛娃神器：免费、凉快、养眼神，泡一天不腻；鼓楼东街28号（东街口站A口步行220米）老馆一楼低幼区（0-6岁）彩色软垫矮书架母婴室，绘本/有声书/触摸书；晋安湖新馆AR互动多可看湖景（周末需公众号提前1天预约）；二楼大孩子借阅区静音舱；三楼传统文化讲习堂常办国学非遗手作

## ⚠️ 注意事项

馆内无餐饮售卖可带水杯有直饮水不能带零食；老馆周一至周五9:00-19:00（周四闭馆）周末8:30-21:00；新馆周一闭馆；周末需预约

## 🍚 餐饮建议

馆内无餐自带水杯；周边东街口商圈餐饮
