# 奇达村

- **分类**：其他目的地
- **来源**：知识库 SPOT_NOTES（已精修）
- **更新**：2026/10/24

## 🎯 玩法推荐

连江安凯乡千年海上渔村，登旗冠顶俯瞰海上渔排风车全景（福建版里约热内卢）；定海湾退潮赶海捡贝壳挖螃蟹、鲍鱼养殖场参观长见识；彩色石头厝古民居渔港日落；全村免费无门票，福州出发自驾约1.5h

## ⚠️ 注意事项

旗冠顶1800级台阶登顶累，带娃量力；山顶风大夏天也带薄外套；台阶多穿防滑鞋雨天不登顶；赶海查潮汐表退潮前1-2h到；礁石湿滑；海鲜适量防娃肠胃不适

## 🍚 餐饮建议

渔村海鲜馆现捞人均50-80（连江鱼丸/鱼面/海蛎煎）；村内渔家民宿100-200/晚可看海
