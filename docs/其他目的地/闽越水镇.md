# 闽越水镇

- **分类**：其他目的地
- **来源**：知识库 SPOT_NOTES（已精修）
- **更新**：2026/10/24

## 🎯 玩法推荐

闽侯竹岐人工复刻汉代闽越水乡（八闽古城），白墙黛瓦拱桥流水随手国风大片；白天民俗巡游非遗手作（剪纸/油纸伞）、傍晚水上舞台《闽音幻境》实景演出、夜间非遗打铁花鱼灯巡游（年节最盛）；沿街古法鱼丸米糕擂茶；大门票约68-98，足够玩一天

## ⚠️ 注意事项

人工古镇评价褒贬不一，主打拍照+文化体验，纯玩乐项目有限；面积大推婴儿车部分石板路略颠带轻便童车/背带；表演有固定时间提前查；距市区约1h车程

## 🍚 餐饮建议

沿街福州特色小吃（鱼丸/米糕/擂茶/青红酒坊）；周边餐饮少建议园内解决
